# UGAF Documentation Index

Living design documents live at the repository root, not here — this folder is
reserved for diagrams/workflows that don't fit a single markdown file. Start with:

- `PROJECT_STATUS.md` / `BUILD_STATUS.md` — source-verified audit and build health snapshots
- `ARCHITECTURE.md` — layer overview and platform priority
- `ARCHITECTURE_DECISIONS.md` — ADRs, in chronological order
- `PLUGIN_ARCHITECTURE.md` / `GAME_PLUGIN_SDK.md` — writing a game plugin
- `PLATFORM_ABSTRACTION.md` — the OS-independent interface layer (Display, Clipboard,
  File System, Network, Process Management, Notifications, Accessibility, Device)
- `ANDROID_TRANSPORT_STRATEGY.md` — ADB/UIAutomator2/Accessibility Service/scrcpy
  comparison and roadmap
- `KNOWN_LIMITATIONS.md` — what doesn't work yet, and why
- `CHANGELOG.md` — what changed, per milestone
